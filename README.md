# Dead Air — Loot & Inventory System

A Unity 3D technical test project for a Unity Developer position.

The project is a prototype of a loot and inventory system for a third-person action RPG set in the industrial, retro-futuristic world of **Dead Air**.

## Project Overview

The goal of this assignment is to implement a modular loot and inventory system using Unity and C#.

### Planned Features

- **Item Data:** Items are configured using ScriptableObjects, including their category, weight, stack size, and dismantling components.
- **Inventory System:** A weight-limited inventory that prevents the player from picking up items when the maximum capacity is exceeded.
- **Loot Pickup:** Support for both automatic and manual item pickup.
- **Loot Highlighting:** An amber on-screen indicator for nearby lootable objects.
- **Item Dismantling:** The ability to dismantle junk items into useful crafting and repair components.
- **Inventory UI:** A simple interface displaying collected items, quantities, and current inventory weight.

## Technical Details

- **Engine:** Unity
- **Programming Language:** C#
- **Platform:** PC
- **Render Pipeline:** Built-in Render Pipeline
- **Architecture:** ScriptableObjects and modular gameplay components
